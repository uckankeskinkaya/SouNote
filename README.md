# SouNote

Kalemle PDF not alma uygulaması (Android, Kotlin).

## APK nasıl kurulur
1. GitHub'da repo → **Releases** → en üstteki `SouNote 0.1.N` → `SouNote.apk` indir.
2. Tablette aç ve kur (gerekirse "bilinmeyen kaynaklar" iznini ver).

Her push'ta GitHub Actions yeni APK derler. Uygulama hep aynı anahtarla
imzalandığı için yeni sürüm eskisinin üstüne kurulur, notlar silinmez.
